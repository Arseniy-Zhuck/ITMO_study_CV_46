# Модуль 2. Технологии компьютерного зрения

Версия: 3.0, редакция с прямой трассировкой по фрагменту РПД и КРМ 3.0.

## Назначение

Модуль содержит лекционные материалы Л6-Л10 и контрольно-измерительные материалы для пяти лабораторных занятий, указанных во фрагменте РПД: Д34, Д35, Д36, ЛР3 и ЛР4. Каждый КИМ связан с индикатором КРМ, уровнем освоения, наблюдаемым результатом, доказательствами выполнения и аналитической рубрикой.

## Быстрая навигация

- `docs/rpd-krm-traceability.md` - основная матрица «РПД → КРМ → результат → КИМ → доказательство».
- `docs/deviations-and-decisions.md` - зафиксированные неоднозначности исходного фрагмента РПД и принятые решения.
- `lectures/` - PDF-презентации Л6-Л10.
- `kim/` - КИМ и методические DOCX для занятий Д34, Д35, Д36, ЛР3, ЛР4.
- `homework/` - пять небольших домашних заданий по лекциям, каждое с отдельной рубрикой.
- `assessment/` - модель измерения, рекомендуемая балльная схема и банк вопросов.
- `methodical-guidelines/` - общие инструкции студентам и преподавателям.
- `quality/` - самопроверка по чек-листу кросс-валидации и отчет о покрытии.

## Важное ограничение балльной схемы

В предоставленном фрагменте РПД отсутствует официальное распределение баллов. В репозитории дана рекомендуемая внутренняя шкала модуля для единообразной проверки. Перед включением в действующую РПД ее необходимо согласовать с принятой в вузе БРС; содержание критериев можно использовать независимо от итогового веса.

## Правила использования генеративного ИИ

Разрешены поиск ошибок, объяснение документации и подготовка черновиков. Сданный код и выводы должны быть воспроизводимы и защищаемы. Преподаватель вправе потребовать изменить параметр, объяснить форму тензора, вывести промежуточную матрицу или выполнить небольшой фрагмент без подсказки.
