# Включение модуля в шаблон Git-репозитория ФОС

Папка `M2-computer-vision-technologies` предназначена для размещения в корне репозитория, созданного по `fos-repository-template`, вместо каталога-заготовки `M2-module-name`.

Требования шаблона к КИМ реализованы следующим образом:

| Требование | Реализация |
|---|---|
| Назначение и проверяемые результаты | разделы каждого `kim-2.x.md` и DOCX |
| Условия выполнения | отдельный раздел КИМ |
| Материалы задания | нумерованные задания в Markdown/DOCX |
| Формат сдачи | перечень проверяемых артефактов |
| Критерии и шкала | отдельная рубрика преподавателю |
| Внешние ресурсы и генеративный ИИ | единые правила в КИМ и методических указаниях |
| Модель измерения | `docs/rpd-krm-traceability.*` и `assessment/measurement-and-scoring.md` |
| Контроль качества | `quality/cross-validation-checklist.md` и `quality/qa-report.md` |

На уровне полного репозитория в корне должны также находиться общая РПД дисциплины, сведения о команде, лицензия, общие ресурсы, проект и промежуточная аттестация. Этот архив содержит только ответственность разработчика блока 2.
