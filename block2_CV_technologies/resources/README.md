# Ресурсы и данные

`original_uploads/` содержит КРМ, чек-лист и предоставленный фрагмент РПД. `source-labs/` содержит исходные авторские ЛР5-ЛР8. Они не являются нормативной нумерацией текущего модуля.

Большие датасеты и видео не следует коммитить. В работе студента указываются URL/источник, дата получения, лицензия, SHA256 или иной идентификатор версии, а также скрипт подготовки данных. Для ЛР4 предусмотрен software-only набор стереопар, чтобы камера Hikrobot не была обязательным условием освоения результата.
