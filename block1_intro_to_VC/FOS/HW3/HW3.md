# Задания для реализации (поиск и анализ контуров + детектирование прямых)

Все функции должны быть реализованы в одном модуле (например, `contour_analysis.py`) с использованием библиотек `numpy` и `opencv-python` (`cv2`). Входные изображения передаются как массивы `np.uint8` (градации серого) или бинарные (0/255), если не указано иное. Выходные данные должны строго соответствовать описанным типам.

---

## Задание 1. `preprocess_image(filepath: str) -> np.ndarray`

**Описание:**  
Загружает изображение по указанному пути, переводит его в градации серого и применяет размытие по Гауссу (размер ядра 5×5, sigma = 1.0). Возвращает подготовленное изображение.

**Вход:**  
- `filepath` – строка, полный путь к файлу.

**Выход:**  
- Изображение `np.uint8` (H×W) после размытия.

---

## Задание 2. `apply_non_maximum_suppression(image: np.ndarray) -> np.ndarray`

**Описание:**  
Вычисляет градиенты изображения с помощью оператора Собеля (размер ядра 3), затем выполняет подавление немаксимумов (non‑maximum suppression) на основе направления градиента. Возвращает изображение после подавления (значения градиента, где сохранены локальные максимумы, остальные обнулены).  
*Примечание:* этот метод не выполняет пороговую фильтрацию, только подавление.

**Вход:**  
- `image` – предварительно сглаженное изображение `np.uint8` (результат Задания 1).

**Выход:**  
- Изображение `np.float64` или `np.uint8` (значения градиента после подавления). Рекомендуется возвращать `np.float64` для сохранения точности.

---

## Задание 3. `apply_canny_edge_detection(image: np.ndarray, low_threshold: int, high_threshold: int) -> np.ndarray`

**Описание:**  
Выполняет полный алгоритм Канни: вычисление градиентов (Собель), подавление немаксимумов, двойную пороговую фильтрацию с последующей трассировкой (связывание краев). Возвращает бинарное изображение контуров (0 и 255).  
*Подсказка:* можно использовать этапы из Задания 2, но для автотестов допустимо использование встроенной функции `cv2.Canny`, если студент объяснит алгоритм. Однако для практики лучше реализовать самостоятельно.

**Вход:**  
- `image` – сглаженное изображение `np.uint8`.  
- `low_threshold` – нижний порог (целое).  
- `high_threshold` – верхний порог (целое).

**Выход:**  
- Бинарное изображение `np.uint8` (0 или 255) размера (H×W).

---

## Задание 4. `extract_contours_and_moments(binary_image: np.ndarray) -> List[Dict]`

**Описание:**  
Находит все контуры на бинарном изображении с помощью `cv2.findContours` (используйте `RETR_EXTERNAL` или `RETR_LIST`). Для каждого контура вычисляет площадь (`cv2.contourArea`) и центр масс через моменты (`cv2.moments`). Возвращает список словарей, каждый из которых содержит контур, площадь и координаты центра.

**Вход:**  
- `binary_image` – бинарное изображение `np.uint8` (0/255).

**Выход:**  
- Список словарей `List[Dict]`, где каждый словарь имеет ключи:  
  - `'contour'` – массив точек контура (`np.ndarray`),  
  - `'area'` – площадь (float),  
  - `'center'` – кортеж `(x, y)` координат центра масс (float).

---

## Задание 5. `filter_contours_by_properties(contours_info: List[Dict], min_area: float, max_area: float, max_aspect_ratio: float, min_circularity: float) -> List[Dict]`

**Описание:**  
Фильтрует список контуров, полученный в Задании 4. Оставляет только те, у которых площадь находится в диапазоне `[min_area, max_area]`, соотношение сторон ограничивающего прямоугольника (`width/height` или `height/width`, берётся меньшее из двух) не превышает `max_aspect_ratio`, а круглость `(4π * area / perimeter^2)` не меньше `min_circularity`. Возвращает отфильтрованный список (с теми же полями, что и на входе).

**Вход:**  
- `contours_info` – список словарей от Задания 4.  
- `min_area` – минимальная площадь (float).  
- `max_area` – максимальная площадь (float).  
- `max_aspect_ratio` – максимально допустимое отношение сторон (float ≥ 1).  
- `min_circularity` – минимальная круглость (float, от 0 до 1).

**Выход:**  
- Отфильтрованный список словарей (структура та же).

---

## Задание 6. `detect_lines_hough(binary_image: np.ndarray, rho: float, theta: float, threshold: int) -> List[Tuple[int, int, int, int]]`

**Описание:**  
Применяет преобразование Хафа для обнаружения отрезков прямых на бинарном изображении. Используйте `cv2.HoughLinesP` с заданными параметрами. Возвращает список обнаруженных отрезков в виде кортежей `(x1, y1, x2, y2)` – координаты начальной и конечной точек каждого отрезка.

**Вход:**  
- `binary_image` – бинарное изображение `np.uint8` (0/255) – обычно результат детектора Канни.  
- `rho` – разрешение по расстоянию (пиксели).  
- `theta` – разрешение по углу (радианы).  
- `threshold` – минимальное количество пересечений для объявления линии.

**Выход:**  
- Список отрезков `List[Tuple[int, int, int, int]]`.

---

## Задание 7. `detect_lines_ransac(binary_image: np.ndarray, num_iterations: int, distance_threshold: float, min_inliers: int) -> List[Tuple[float, float, float]]`

**Описание:**  
Выполняет поиск прямых линий на бинарном изображении с использованием алгоритма RANSAC. Извлеките все координаты ненулевых пикселей (краевые точки). Итеративно выбирайте случайные пары точек, вычисляйте параметры прямой (в нормальной форме: `(rho, theta)` или коэффициенты `(a, b, c)` для уравнения `ax + by + c = 0`), подсчитывайте количество инлайеров (точки, расстояние до прямой меньше `distance_threshold`). Если количество инлайеров ≥ `min_inliers`, сохраните прямую, удалите инлайеры из набора точек и повторите поиск до тех пор, пока не останется меньше `min_inliers` точек или не будет выполнено `num_iterations` итераций. Верните список найденных прямых в виде коэффициентов `(a, b, c)` (нормализованных, например, `a^2 + b^2 = 1`).

**Вход:**  
- `binary_image` – бинарное изображение `np.uint8` (0/255).  
- `num_iterations` – максимальное число итераций для каждой прямой.  
- `distance_threshold` – максимальное расстояние от точки до прямой, чтобы считаться инлайером.  
- `min_inliers` – минимальное число инлайеров для подтверждения прямой.

**Выход:**  
- Список прямых `List[Tuple[float, float, float]]`, каждая прямая задана уравнением `ax + by + c = 0`.
